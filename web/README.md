# Defold Asset Store Web UI

Веб-интерфейс для Defold Asset Store, который позволяет устанавливать ассеты прямо из браузера через HTTP API редактора Defold.

## Особенности

- 🌐 Веб-интерфейс с темной темой в стиле Defold
- 📦 Поддержка всех типов stores: Dependencies, Druid Widgets, Editor Scripts
- 🔍 Поиск и фильтрация по автору, тегам
- 📊 Сортировка по различным критериям
- ⚡ Установка ассетов одним кликом через HTTP API редактора
- 💾 Автосохранение порта редактора в localStorage

## Использование

### Из редактора Defold

1. Откройте меню `Project` → `[Asset Store] Open Web Page`
2. Веб-страница откроется автоматически с параметром порта
3. Порт редактора будет автоматически заполнен в поле "Editor Port"

### Вручную

1. Откройте `https://insality.github.io/asset-store/web/` в браузере
2. Введите порт редактора Defold в поле "Editor Port" (например, `54627`)
3. Порт можно найти в логах редактора при запуске HTTP сервера

## Установка ассетов

1. Выберите нужный store (Dependencies, Druid Widgets, или Editor Scripts)
2. Найдите нужный ассет через поиск или фильтры
3. Нажмите кнопку "Install" на карточке ассета
4. Ассет будет установлен в ваш проект через HTTP API редактора

### Локальная разработка

Для локальной разработки можно использовать простой HTTP сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (http-server)
npx http-server

# Затем откройте http://localhost:8000/web/
```

## Технологии

- **Vue.js 3** (CDN) - реактивность и компоненты
- **Vanilla CSS** - стили без зависимостей
- **Fetch API** - загрузка данных и установка ассетов

## API

Веб-интерфейс использует следующие эндпоинты:

- `GET /install?author={author}&id={id}&type={type}` - установка ассета
  - `author` - имя автора (опционально)
  - `id` - ID ассета (обязательно)
  - `type` - тип ассета: `dependency`, `widget`, или `editor_script`

## Цветовая схема

Интерфейс использует темную тему в стиле Defold:

- Фон: `#1e1e1e`
- Вторичный фон: `#252526`
- Акцентный цвет: `#4a9eff`
- Текст: `#cccccc`

## Поддержка

Если у вас возникли проблемы:

1. Убедитесь, что редактор Defold запущен
2. Проверьте, что HTTP сервер редактора активен (порт должен быть доступен)
3. Проверьте консоль браузера на наличие ошибок
4. Убедитесь, что вы используете правильный порт редактора

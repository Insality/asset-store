Локальное тестирование Defold Asset Store

1. Запустите локальный HTTP сервер

Откройте терминал в директории web/ и выполните одну из команд:

Python 3:

python3 -m http.server 8000

Python 2:

python -m SimpleHTTPServer 8000

Node.js (http-server):

npx http-server -p 8000

PHP:

php -S localhost:8000

2. Откройте в браузере

Откройте в браузере:

http://localhost:8000/index.html

Или просто:

http://localhost:8000/

3. Укажите порт редактора

В поле "Editor Port" введите порт вашего редактора Defold (например, 54627).

Порт можно найти в логах редактора при запуске HTTP сервера.

4. Тестирование установки

Для тестирования установки:

  1. Убедитесь, что редактор Defold запущен
  2. Проверьте, что HTTP сервер редактора активен (должен быть доступен порт)
  3. Выберите ассет и нажмите "Install"
  4. Проверьте консоль браузера (F12) на наличие ошибок

5. Тестирование без редактора

Вы можете протестировать интерфейс без запущенного редактора:

  • Все функции поиска и фильтрации будут работать
  • Карточки ассетов будут отображаться
  • Кнопка "Install" покажет ошибку, если редактор не запущен (это нормально)

Важно!

При локальном тестировании данные будут загружаться с GitHub Pages:

  • https://insality.github.io/asset-store/dependencies_store.json
  • https://insality.github.io/asset-store/druid_widget_store.json
  • https://insality.github.io/asset-store/assets_editor_scripts_store.json

Для тестирования с локальными JSON файлами нужно изменить BASE_URL в app.js на http://localhost:8000 и скопировать JSON файлы в директорию web/.
